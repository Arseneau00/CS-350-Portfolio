# CS-350 Emerging Systems Architectures and Technologies

## Project Summary

For this course I worked on a few different projects using a Raspberry Pi and Python. The two projects I chose for my portfolio are my final thermostat project and my Module Five milestone. Both projects involved programming hardware components and getting them to communicate with the software.

For the final project I created a thermostat system that could monitor temperature and switch between heating, cooling, and off modes. I used buttons for input, LEDs to show the current mode, and an LCD screen to display information. The project also involved using UART communication and a state machine to control how the system operated.

For my Module Five milestone I worked on controlling hardware through Python and using a state machine to manage different operations. This helped me better understand how to handle inputs and outputs on the Raspberry Pi.

## What did you do particularly well?

I think I did pretty well with getting the different hardware components working together. At the start of this course I wasn't very familiar with programming a Raspberry Pi or working with GPIO pins. As I worked through the different modules I got more comfortable with the hardware and understanding how the code controlled everything. I also think I did a good job troubleshooting problems and figuring out what needed to be changed when something wasn't working.

## Where could you improve?

One area I could improve on is writing the code more independently. There were times where I had to go back through the course resources or example code to understand how certain functions worked. I also want to get better at troubleshooting hardware connections since even a small wiring mistake can cause problems. I feel like I learned quite a bit throughout this course but I still have more to learn.
